≠

≠

lo permitido por condiciones/restricciones.

ACCESSIBLE:

C. ARCHITECTURAL SEED

Definición:

Representación compacta, generativa y revisable de una selección o interpretación de condiciones, referencias, intenciones, relaciones o posibilidades desde la cual puede iniciarse una trayectoria proyectual.

Debe ser diferente de:

COMPUTATIONAL SEED.

D. PARTI / PARTIDO ARQUITECTÓNICO

Definición:

Hipótesis organizadora integral y revisable mediante la cual se sintetizan determinantes, interpretaciones e intenciones relevantes del proyecto en una posición arquitectónica capaz de orientar coherentemente relaciones espaciales, funcionales, formales, contextuales y, cuando corresponda, tectónicas.

No imponer que todo proceso tenga un único parti explícito.

Permitir:
- multiple parti hypotheses;
- parti emerging through exploration;
- parti/form/problem co-evolution.

E. REALIZATION FAMILY

Un mismo parti debe poder tener múltiples realizaciones.

PARTI ≠ TEMPLATE.

F. DESIGN MEMORY

Debe preservar:
- seeds;
- partis;
- branches;
- candidates;
- mutations;
- rejections;
- observations;
- human judgments;
- backtracks;
- reframes;
- failed explorations.

DESIGN MEMORY ≠ ARCHITECTURAL KNOWLEDGE.

G. BACKTRACK

Retorno a un nivel anterior del proceso conservando evidencia válida adquirida.

BACKTRACK ≠ UNDO.

H. REFRAME

Cambio del entendimiento/modelo del problema.

BACKTRACK ≠ REFRAME.

Pueden ocurrir juntos.
