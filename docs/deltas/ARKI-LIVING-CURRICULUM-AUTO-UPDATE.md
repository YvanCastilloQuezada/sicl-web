# ARKI — Currículo vivo: actualizaciones automáticas

Este archivo es el índice incremental que conecta cada nuevo delta con los tres volúmenes del Libro Vivo ARKI.

Cada entrada registra la fuente, el hash, el estado epistemológico, los objetivos curriculares y las evidencias pendientes. La recepción de un archivo no se interpreta como aprendizaje. La actualización automática significa **registrar y preparar la integración**, no canonizar conocimiento ni modificar decisiones de diseño.

## Reglas permanentes

1. Cada delta se registra una sola vez por su hash SHA-256.
2. Cada delta se conserva como fuente versionada; nunca se sobrescribe silenciosamente.
3. Cada delta se vincula a Volumen I — Fundamentos, Volumen II — Enseñar Arquitectura y Volumen III — ARKI.
4. La información suministrada, recuperada o ejecutada no se reporta como aprendizaje por sí misma.
5. La promoción de conocimiento requiere baseline K0, observaciones, persistencia K1, transferencia, contraejemplo y revisión humana.
6. Los deltas anteriores no se eliminan porque un delta nuevo no los repita.
7. La autoridad humana permanece final para canonización, decisiones de diseño, ganadores y aprobación profesional.

```text
ARCHIVO ADJUNTO
→ DETECCIÓN / IDENTIFICACIÓN

```
