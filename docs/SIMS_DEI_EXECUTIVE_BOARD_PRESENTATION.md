# Guion ejecutivo para junta directiva

El guion ejecutivo oficial se mantiene en el repositorio Core para evitar divergencia entre arquitectura, handover y presentación:

[`sicl-core/docs/SIMS_DEI_EXECUTIVE_BOARD_PRESENTATION.md`](https://github.com/YvanCastilloQuezada/sicl-core/blob/main/docs/SIMS_DEI_EXECUTIVE_BOARD_PRESENTATION.md)

## Uso

Utilice este guion junto con:

- `SIMS_DEI_FIRST_CONTACT_MANUAL.md` para la demostración inicial.
- `SIMS_DEI_FRONTEND_HANDOFF.md` para explicar el estado del frontend.
- `SIMS_DEI_PROJECT_HANDOVER.md` para revisar arquitectura, pruebas, seguridad y pendientes.

La presentación debe conservar una afirmación esencial: SiMS-DeI puede analizar y proponer, pero la autoridad de decisión permanece humana.
