# ARKI — BODY MAP / TRIPLE AUDIT V1

**Date:** 2026-10-05  
**Repository scope:** `YvanCastilloQuezada/sicl-core` + `YvanCastilloQuezada/sicl-web` + recovered Git history  
**Method:** three independent passes: current code surface, historical lineage, and evidence/status cross-check.  
**Rule:** no evidence = no green. IMPLEMENTED ≠ EXECUTED ≠ VERIFIED ≠ FROZEN.

## 0. Constitutional body

ARKI is treated as one governed artificial cognitive-computational organism specialized in architecture and habitat.

- **Identity / DNA:** Lex ARKI + 3D-FIRST + constitutional principles, including PF-05 Mutual Care.
- **Architectural authority:** D-2 — meaning, intent, constraints, decisions, architectural state.
- **Operational geometry authority:** AGK — sole canonical geometry authority.
- **External execution boundary:** Capability Fabric — discovers/resolves/executes providers; cannot decide architecture or canonical geometry.
- **Human Authority:** final owner/professional/regulatory gate where required.
- **Knowledge gate:** Delta 6.2 — sole formal epistemic ingestion/promotion system.

## 1. Triple-audit method

### PASS A — Anatomical audit: what exists now
Inspected current repository surfaces, source directories, shared contracts, pages, tests, registries and master-map state.

### PASS B — Genealogical audit: what existed and evolved
Searched commit history for Site Intelligence, Open-Meteo, environmental/solar, GIS, IFC, drawing, visualization, agents, knowledge, parametric, PWA/WebXR, costs, families, Pareto and related motors/capabilities.

### PASS C — Epistemic audit: what may actually be claimed
Cross-checked implementation claims against commits reporting tests/build/runtime evidence and preserved explicit limitations. Historical code or a contract alone is not classified as current VERIFIED capability.

## 5. External technology / motor doctrine

The registry contains many candidate masters/providers (GIS, energy, structures, CFD, BIM, optimization, LCA, acoustics, etc.). Their presence in the registry does not mean installed or operational.

Canonical evolution:

`external motor/program → practicum/oracle → observed routine → Delta 6.2 candidate → curated knowledge → tested script/kernel → native ARKI capability`

Policy: **OWN CAPABILITY FIRST. EXTERNAL ENGINE WHEN NECESSARY.**

## 6. Main systemic finding

ARKI does not primarily suffer from absence of organs. It has many organs, several surprisingly mature. The larger problem is **assembly and current-state visibility**:

1. capabilities are distributed between Core, Web, historical branches/commits and frozen documents;
2. some old implementations are more advanced than the current map reflects;
3. several capabilities have evidence in bounded checkpoints but lack a current whole-organism regression;
4. frontends expose different slices of the same organism;
5. Site Intelligence, design generation, BIM/drawing, parametric, Field/AR, cost and agents need to be wired into one visible nervous system without creating second authorities.

## 7. Map semantics for the frontend

Every organ in the future Body Map must expose:

- canonical name and organ class;
- authority / owner;
- repository + locus;
- dependencies and outgoing connections;
- current state: CLAIM / DESIGN / IMPLEMENTED / EXECUTED / OBSERVED / VERIFIED / FROZEN / UNKNOWN / BLOCKED / SUPERSEDED;
- integration: CONNECTED / PARTIAL / DISCONNECTED / CONFLICTING;
- last evidence commit/test;
- known gaps;
- next exact action;
- whether it can be invoked from the frontend now.

Color alone must never carry epistemic meaning; text state is mandatory.

## 9. Audit conclusion

**PASS A:** ARKI has a broad current anatomical base.  
**PASS B:** history proves additional mature organs that are not obvious from HEAD alone.  
**PASS C:** many are implemented/verified in bounded historical checkpoints, but whole-organism current verification is incomplete.

Therefore the correct next phase is not indiscriminate feature creation. It is **assembly, visibility, reconnection and regression of the existing organism**, followed by filling only demonstrated gaps.
