## Phase A — blind result

ARKI derived four activity systems: repair and learning, gathering and exchange, staff/storage/support, and ordinary/emergency exit. It generated two topology hypotheses without selecting a winner:

1. **B-CANDIDATE-01:** shared threshold → learning → gathering, with controlled support access.
2. **B-CANDIDATE-02:** gathering → learning, with separated support and storage routes.

These are semantic hypotheses, not construction documents or permit-ready plans. The accompanying SVG is a comparison board, not a geometric floor plan.

Both variants preserve explicit spaces, walls, doors and a conceptual public route. Accessibility compliance, capacity, code applicability, structural performance, construction assemblies and permit readiness remain **UNKNOWN** or **NOT_ASSESSED**. Both variants remain `HYPOTHESIS`, `permitReady = false`, `constructionReady = false`, and require human review.
