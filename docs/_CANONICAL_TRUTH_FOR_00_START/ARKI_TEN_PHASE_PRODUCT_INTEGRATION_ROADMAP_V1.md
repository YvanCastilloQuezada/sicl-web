# ARKI — Ten-Phase Product Integration Roadmap V1

**Status:** PRODUCT-OWNER DIRECTION / IMPLEMENTATION MAP
**Date:** 2026-10-05
**Purpose:** turn the distributed repository archive into one visible ten-phase execution spine. This roadmap does not rewrite historical evidence and does not promote documentary ideas to implemented capability.

## Governing rules
1. Exactly ten product phases: F1–F10.
2. Current declaration remains **F6 IN_PROGRESS**. F1–F5 remain **RECONCILIATION_REQUIRED** until historical gates are mapped with SHA/code/tests; F7–F10 are future integration phases.
3. Ideas are scheduled, not canonized. IDEA != KNOWLEDGE; knowledge still enters only through Delta 6.2.
4. Existing organs are connected before parallel engines are invented.
5. D-2 remains semantic authority; AGK/OCCT remains sole operational geometry authority.
6. Every phase has visible entry gate, work packages, evidence, exit gate, dependencies and UNKNOWNs.
7. The Command Center is the owner-facing live schedule: every idea/capability must show NOW / NEXT / LATER, target phase, status and evidence.

## Time model
Calendar dates are deliberately not invented. Use evidence-gated waves:
- **NOW — F6 closure:** AGK DELTA-005 P6→P10, constructive identity, naming, transaction/persistence/concurrency/OCCT integration; reconcile F1–F5 evidence in parallel without reopening frozen work.
- **NEXT — F7:** professional technical development only after F6 geometry/identity gates.
- **THEN — F8:** dossier assembly only after professional model and discipline evidence exist.
- **LATER — F9:** field/as-built/digital-twin loop after delivery model is stable.
- **LIFECYCLE — F10:** operations/economic feedback and learning loop after project delivery/field lineage exists.
- **TRANSVERSAL:** Delta 6.2, University, Research, ACS, AI Lab, D-2, Human Authority, Security, Evidence and AR-LU governance operate across phases but do not create parallel truth.

Every recovered or new idea receives: IDEA_ID, SOURCE, STATUS, TARGET_PHASE, PREREQUISITES, EVIDENCE_GATE, OWNER/AUTHORITY, IMPLEMENTATION_LINK, TEST_LINK, RESULT.

CAPTURED → UNDER_REVIEW → PRIORITIZED → SCHEDULED(F#) → IN_DEVELOPMENT → IMPLEMENTED → VERIFIED → INCORPORATED, with exits FROZEN / REJECTED / UNKNOWN.
