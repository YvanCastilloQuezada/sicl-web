# ARKI — 0-Historical

Rama documental aislada de `main`. No representa el estado de ejecución ni autoriza integración de código histórico.

## Archivo preparado

Se preparó un paquete local organizado en siete categorías temáticas con originales, contenido descomprimido y manifiesto SHA-256. **La carga masiva de los archivos todavía está pendiente**; no confundir la creación de esta rama con la publicación de todo el archivo.

Carpetas previstas:
1. Historia, gobierno y documentos generales
2. Kernel, geometría, contratos y pruebas
3. Conocimiento, aprendizaje y semántica
4. Interfaz, BIM, escena y expedientes
5. Auditorías, handoffs y evidencias
6. Predicción, simulación y servicios
7. Proyectos separados y referencias

Cada fuente conserva su ZIP o documento original, además de la extracción cuando corresponde. No ejecutar scripts archivados sin auditoría.
