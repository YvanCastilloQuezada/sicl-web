# ARKI — Archivo histórico 0-Historical

Archivo documental. **No es código vigente ni autoriza implementación**.

Cada paquete conserva su archivo original en `00_original` y sus archivos extraídos en `01_extraido`. Las siete carpetas son categorías temáticas, no fases F1–F10. Consulte `MANIFIESTO.json` para SHA-256 y procedencia. Los duplicados se conservan por trazabilidad. No ejecutar scripts históricos sin auditoría.

La cronología debe determinarse de fechas documentales y commits, no de marcas de tiempo ZIP.
