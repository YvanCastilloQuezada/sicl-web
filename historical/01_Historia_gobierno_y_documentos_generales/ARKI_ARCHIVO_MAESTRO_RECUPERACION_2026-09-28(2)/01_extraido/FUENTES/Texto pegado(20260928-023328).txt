3.3 Estructura del elemento
python
PropertyValue = str | int | float | bool

@dataclass(frozen=True)
class ArchiElement:
    element_id: ArchiElementId
    kind: ElementKind
    project_id: str
    name: str
    geometry: "ArchiGeometry"
    hosting: tuple[ArchiElementId, ...] = ()
    contained_in: ArchiElementId | None = None
    properties: tuple[tuple[str, PropertyValue], ...] = ()
    version: int = 1
    provenance: tuple[str, ...] = ()

    def __post_init__(self):
        if not self.name.strip(): raise ValueError("name required")
        if self.version < 1: raise ValueError("version >= 1")
        if self.hosting and self.contained_in is not None:
            raise ValueError("cannot host and be contained simultaneously")
        keys = [k for k, _ in self.properties]
        if keys != sorted(keys): raise ValueError("properties must be sorted")
        if len(keys) != len(set(keys)): raise ValueError("properties keys unique")

    def content_hash(self) -> str:
        state = {
            "schema": "archi-element-state-v1",
            "elementId": self.element_id.value,
            "kind": self.kind.value,
            "projectId": self.project_id,
            "name": self.name,
            "geometry": self.geometry.to_canonical(),
            "hosting": [h.value for h in self.hosting],
            "containedIn": self.contained_in.value if self.contained_in else None,
            "properties": [[k, _serialize_property_value(v)] for k, v in self.properties],
            "version": self.version,
        }
        canonical = json.dumps(state, sort_keys=True, separators=(",", ":"), ensure_ascii=False)
        return hashlib.sha256(canonical.encode("utf-8")).hexdigest()
provenance queda FUERA del content_hash. Cambio administrativo no altera identidad semántica.

3.4 Properties tagged union
python
def _serialize_property_value(v: PropertyValue) -> object:
    if isinstance(v, bool):   return {"t": "bool",  "v": v}
    if isinstance(v, int):    return {"t": "int",   "v": v}
    if isinstance(v, float):  return {"t": "float", "v": round(v, 6)}
    if isinstance(v, str):    return {"t": "str",   "v": v}
    raise TypeError(f"unsupported: {type(v)}")
bool antes que int. Floats canonicalizados a 6 decimales.

6.3 Versionado unificado
ArchiElement.version es la verdad canónica.

Mutación aplicada: version(n+1) = version(n) + 1.

Cambio de solo provenance: no incrementa versión.

No hay dos contadores independientes.

6.4 Hosting semantics
Mutación del host propaga al hosted:

MOVE W-01 +1.00 m sur → D-01 (HOSTED_IN W-01) se mueve.

Si D-01 queda fuera de rango → H-003 INVALID → H-004 ESCALATE.

Nunca se deja un hosted flotando en silencio.

7. Semántica transaccional — RT-D12-03
7.1 Modelo
text
CANONICAL STATE n
      ↓
PROPOSED MUTATION
      ↓
CANDIDATE STATE
      ↓
A-002 (operation-specific)
      ↓
H-001 / H-002 / H-003 / H-004 / H-005
      ↓
DECISION
   ↙          ↘
NO COMMIT    COMMIT
               ↓
        CANONICAL STATE n+1
Regla dura: el canonical state permanece intacto hasta que la decisión sea APPLIED. Cualquier otro resultado no modifica el canonical state, no parcialmente, no transitoriamente, no como evento:

text
BLOCKED, NEEDS_REVIEW, FAILED, INVALID, UNKNOWN,
ESCALATE, REQUIRES_AUTHORITY
7.2 Estados distinguidos
python
class MutationLifecycle(str, Enum):
    PROPOSED   = "PROPOSED"    # mutación recibida
    EVALUATED  = "EVALUATED"   # A-002 + H-002/H-003 completados, sin commit
    AUTHORIZED = "AUTHORIZED"  # aprobado por autoridad cuando se requiere
    APPLIED    = "APPLIED"     # canonical n → n+1 (único estado que muta)
    PUBLISHED  = "PUBLISHED"   # representación (IFC) regenerada y emitida
7.3 Qué se registra sin afirmar commit
Eventos de evaluación (A-002 report, H-002 impacto, H-003 validez, H-004 plan) se registran como audit events sin DERIVATION_RECORDED de la mutación.

Solo en APPLIED se registra el DerivationRecord de la nueva versión del elemento.

El registro previo no afirma falsamente que el estado arquitectónico cambió.
