Inyección 01 — declared_state vs effective_state (RT-03)
Archivo: src/sicl/a002/model.py

Modificación a KnowledgeItem:

Añadir dos campos calculados (no declarados):

python
@dataclass(frozen=True)
class KnowledgeItem:
    # ... campos actuales ...
    declared_state: KnowledgeState        # lo que el input declara
    effective_state: KnowledgeState       # lo que el sistema acepta tras validación
    downgrade_reason: str = ""            # por qué se degradó
Regla de derivación (en engine.py, no en el __post_init__):

declared_state = KNOWN + sin evidencia válida → effective_state = OBSERVED, downgrade_reason = "KNOWN_WITHOUT_EVIDENCE".

declared_state = KNOWN + evidencia inválida (cross-project, scale wrong, hash mismatch) → effective_state = OBSERVED, downgrade_reason = "EVIDENCE_INVALID".

declared_state = KNOWN + evidencia válida → effective_state = KNOWN.

declared_state = ASSUMED + reason presente → effective_state = ASSUMED.

declared_state = ASSUMED sin reason → effective_state = UNKNOWN, downgrade_reason = "ASSUMED_WITHOUT_REASON".

Resto de estados → iguales entre declared y effective.

Retrocompatibilidad: KnowledgeItem.state se mantiene como alias de declared_state para no romper tests existentes. En v1.4.x se puede deprecar.

Inyección 03 — EvaluationIdentityPayload canónico → evaluation_id (RT12-06)
Archivo nuevo: src/sicl/a002/identity.py

python
@dataclass(frozen=True)
class EvaluationIdentityPayload:
    schema: str = "a002-evaluation-identity-v1"
    project_id: str
    snapshot_fingerprint: str
    profile_id: str
    profile_version: int
    operation: str

    def to_dict(self) -> dict[str, Any]:
        return {
            "schema": self.schema,
            "projectId": self.project_id,
            "snapshotFingerprint": self.snapshot_fingerprint,
            "profileId": self.profile_id,
            "profileVersion": self.profile_version,
            "operation": self.operation,
        }

def compute_evaluation_id(payload: EvaluationIdentityPayload) -> str:
    canonical = json.dumps(payload.to_dict(), sort_keys=True, separators=(",", ":"))
    return hashlib.sha256(canonical.encode("utf-8")).hexdigest()
Modificación a SufficiencyResult: añadir evaluation_id: str y identity_payload: dict.

Modificación a A002H005Gate.check: validar también result.evaluation_id == compute_evaluation_id(expected_payload).
