4.3 SufficiencyStatus
python
class SufficiencyStatus(str, Enum):
    SUFFICIENT   = "SUFFICIENT"
    INSUFFICIENT = "INSUFFICIENT"
    UNKNOWN      = "UNKNOWN"
Regla semántica de UNKNOWN: el reporte es UNKNOWN cuando el snapshot mismo no es interpretable (tipo incorrecto, dict malformado, etc.). No es lo mismo que INSUFFICIENT — donde el snapshot está bien formado pero le faltan campos.

4.4 Catálogo v1 de campos (propuesta base)
Campos críticos para formular un problema arquitectónico:

text
brief              — descripción del encargo
activities         — actividades previstas
subjects           — actores/usuarios
relationships      — relaciones funcionales entre actividades
conditions         — restricciones del sitio o del cliente
constraints        — restricciones normativas o dimensionales
site              — contexto físico mínimo
objectives         — objetivos declarados
Campos opcionales:

text
preferences        — preferencias no vinculantes
knowledge          — conocimiento recuperado
unknowns           — UNKNOWNs explícitos
typology          — tipología declarada
Este catálogo requiere firma del PO antes de implementarse. No es universal. Es v1 y es revisable.

5. Reglas de comportamiento
5.1 Determinismo
Mismo input → mismo output.

Sin Math.random, sin Date.now, sin red, sin providers.

canonical_dict() reproducible byte-a-byte.

5.2 Fail-closed
Snapshot None, no-dict, o con tipo incorrecto → UNKNOWN, nunca SUFFICIENT.

Si un campo crítico aparece con valor None, "", [], {} → cuenta como vacío → INSUFFICIENT.

Ningún camino retorna SUFFICIENT si falta algún campo crítico.

5.3 No invención
El reporte no sugiere valores para campos faltantes.

El reporte no infiere campos por proximidad semántica.

El reporte no propone default values.

5.4 Read-only
El módulo no modifica el snapshot.

No escribe al ledger.

No genera eventos.

No llama a H-001..H-005.

5.5 Human Authority
A-002 no decide. Solo informa.

El reporte es una observación, no una decisión.

La interpretación de "qué hacer con INSUFFICIENT" queda para el humano.
