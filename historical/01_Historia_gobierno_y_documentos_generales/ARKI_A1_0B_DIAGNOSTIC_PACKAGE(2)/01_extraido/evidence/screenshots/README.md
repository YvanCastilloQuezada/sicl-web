# Screenshots evidence

A1.0B no incluye capturas genéricas reutilizadas entre rutas. Las capturas del navegador sólo se conservan cuando pueden vincularse de forma inequívoca con la URL y el momento de observación. En esta ejecución, la herramienta produjo estados visuales con navegación concurrente y no se incorporan imágenes ambiguas al paquete.

La evidencia primaria queda en los registros de navegación, textos de página, consola, recursos y matrices de clasificación.
