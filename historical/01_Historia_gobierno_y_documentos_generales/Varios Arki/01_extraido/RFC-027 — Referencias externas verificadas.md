# RFC-027 — Referencias externas verificadas

- Autodesk Revit API: https://aps.autodesk.com/developer/overview/revit-api
  - Revit ofrece una API .NET para automatizar tareas y extender el software.
  - Autodesk publica guía de desarrollador, SDK y ejemplos.

- Graphisoft IFC Model Exchange with Archicad for Revit: https://www.graphisoft.com/en-hr/downloads/add-ons/revit-ifc-model-exchange-for-archicad/
  - El add-in documentado permite Improved IFC Import, Link IFC y Export to Archicad.
  - El intercambio se basa en la API de Revit y está orientado a interoperabilidad IFC.

- OGC API Features: https://ogcapi.ogc.org/features/overview.html
  - Define APIs modulares para colecciones y entidades geoespaciales.
  - Soporta consultas por bbox, paginación, GeoJSON y declaración de CRS.

- Ollama OpenAI compatibility: https://docs.ollama.com/api/openai-compatibility
  - Ollama ofrece servidor local compatible con chat completions y JSON mode.
  - La documentación indica soporte para herramientas, salidas reproducibles y modelos locales.
  - La API local usa normalmente http://localhost:11434/v1/ y requiere un valor de API key ignorado por Ollama.
