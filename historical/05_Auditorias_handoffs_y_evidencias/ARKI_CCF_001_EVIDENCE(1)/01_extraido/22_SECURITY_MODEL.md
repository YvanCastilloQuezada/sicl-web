# Security Model

The Command Center is privileged infrastructure. The UI is not authority. Action buttons create auditable intents and cannot bypass the Autopilot mandate. No browser control directly grants permission, commits canonical state, changes the mandate or skips Human Gates. The current static projection does not claim production authentication or multi-user authorization.

This CCF artifact is bounded by Human Authority, PF-H01, the canonical-state firewall, and the explicit scope of ARKI-CCF-001. CCF is observability, navigation, coordination and governed control; it is not ARKI's brain, a truth store, a canonical mutation engine, or a source of professional certification.
