# Aurora R1 Comparison Protocol

R1 is not executed by this order. Compare the frozen input hash, repository HEAD/worktree, contamination scan, task matrix, reason/calculate/model/verify counts, UNKNOWN quality, required-input count, adversarial detection/misses, C1–C80 activation distribution, tool deficits, failure distribution, and professional-validation boundaries. A change in scoring definitions is itself a protocol change and must be recorded before R1.
