# E4.5 — Pruebas de contratos especializados

| ID | Caso | Criterio |
|---|---|---|
| E4-T01 | Escalera recta entre dos niveles | Geometría, peldaños, descanso y advertencias coherentes |
| E4-T02 | Escalera accesible | Pendiente, descansos y pasamanos conservados |
| E4-T03 | Ascensor camillero | Cabina, puertas, foso, recorrido y núcleo relacionados |
| E4-T04 | Cambio de recorrido de ascensor | Elementos y documentos afectados marcados |
| E4-T05 | Red de oxígeno | Fuente, presión, sector, terminales y alarma relacionados |
| E4-T06 | Red de vacío | Puntos, sectorización, advertencias y mantenimiento trazables |
| E4-T07 | CCTV | Cobertura, orientación, red, alimentación y almacenamiento relacionados |
| E4-T08 | Control de acceso | Puerta, lector, controlador, emergencia y alimentación relacionados |
| E4-T09 | Cambio de especialista | Permisos y auditoría actualizados |
| E4-T10 | Gate profesional incompleto | Resultado permanece `BLOCKED` y no se emite como definitivo |

Estos casos son criterios documentales. Ninguno se marca `PASS` hasta que exista motor, fixture, comando y output real.
