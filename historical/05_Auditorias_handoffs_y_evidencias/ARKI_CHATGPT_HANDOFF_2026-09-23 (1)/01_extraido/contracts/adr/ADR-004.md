# ADR-004 — Persistencia local-first

**Estado:** Aprobado para ejecución de E6  
**Fecha:** 2026-09-23

## Decisión

IndexedDB es el almacenamiento primario de E6. La persistencia remota sólo puede existir detrás de una interfaz explícita y no se simula un servidor real.

## Reglas

- No hay fallback remoto silencioso.
- Si no existe configuración remota, la UI informa: `PERSISTENCIA REMOTA NO CONFIGURADA — FALLBACK A LOCAL-FIRST`.
- Exportación e importación son la vía de portabilidad local.
- Las migraciones se versionan y no se permite downgrade destructivo.

## Límites

Este ADR no afirma multiusuario, colaboración en vivo ni persistencia productiva server-side.
