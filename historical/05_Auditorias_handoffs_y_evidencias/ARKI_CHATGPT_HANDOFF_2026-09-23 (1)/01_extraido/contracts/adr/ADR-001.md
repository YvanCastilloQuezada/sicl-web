# ADR-001 — Tecnología del visor 3D

**Estado:** Aprobado para E5 Revisado  
**Fecha:** 2026-09-23

## Decisión

ARKI utiliza Three.js con React Three Fiber y Drei para el visor 3D interactivo.

Versiones fijadas en el baseline E5:

- `three`: `0.186.0`
- `@react-three/fiber`: `9.8.0`
- `@react-three/drei`: `10.7.8`

## Justificación

La decisión P0-1 autorizó Three.js/R3F. La combinación permite representar el `SceneModel`, manejar selección semántica, cámaras, controles de navegación, capas y extensiones técnicas sin crear un renderer propietario prematuro.

## Alternativas descartadas

Babylon.js y WebGPU puro quedan fuera de E5 para evitar cambiar el stack después de haber construido el E5-PREVIEW.

## Límites

Este ADR no afirma compatibilidad universal de WebGL ni exportación IFC/RVT. Cada capacidad nueva debe tener una prueba de compatibilidad con React 19, evidencia reproducible y fallback explícito cuando corresponda.
