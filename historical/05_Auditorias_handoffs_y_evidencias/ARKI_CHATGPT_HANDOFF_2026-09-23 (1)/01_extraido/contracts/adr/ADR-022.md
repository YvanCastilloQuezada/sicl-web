# ADR-022 — GlobalId gobernado

**Estado:** Aprobado para ejecución de E6  
**Fecha:** 2026-09-23

## Decisión

El `GlobalId` IFC se deriva determinísticamente de `ArchiElementId + projectId + versionNumber`, usando SHA-256 y una codificación gobernada compatible con la longitud IFC.

## Reglas

- No se usa `Math.random()` ni `Date.now()` para identidades críticas.
- El mapa ArchiElementId ↔ GlobalId es bidireccional, versionado y persistido con el snapshot.
- Cambios geométricos no cambian la identidad lógica.
- Colisiones se detectan y producen error verificable.

## Límites

La identidad gobernada no implica round-trip IFC completo; eso requiere parser, exporter, fixtures y lossReport.
