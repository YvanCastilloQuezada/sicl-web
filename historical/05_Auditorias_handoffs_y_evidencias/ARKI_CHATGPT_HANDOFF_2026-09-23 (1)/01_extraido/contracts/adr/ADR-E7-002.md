# ADR-E7-002 — Planificación 4D

**Estado:** Aprobado para E7  
**Fecha:** 2026-09-23

Las actividades 4D se vinculan a elementos o partidas mediante referencias estables. Las precedencias forman un grafo acíclico validado. La ruta crítica se calcula sobre duración y dependencias, y los ciclos se rechazan.
