# ADR-019 — Captura reproducible de canvas WebGL

**Estado:** Aprobado para ejecución de P1  
**Fecha:** 2026-09-23

## Decisión

La captura preferida del visor E5 es `canvas.toDataURL("image/png")` desde el propio componente o una ruta de captura controlada. Si el entorno no permite esa ruta, se utilizará Playwright headless con WebGL habilitado. `html2canvas` queda como último fallback y no se considerará equivalente si no captura el contenido WebGL real.

## Evidencia obligatoria

Cada captura debe conservar:

- PNG.
- SHA-256.
- Viewport.
- Nivel.
- Disciplina.
- Capas visibles.
- Selección.
- Estado del modelo.
- Fecha de generación del artefacto.

## Límites

Una captura sin hash o una imagen que omita el canvas WebGL no satisface P1. Este ADR no convierte una captura visual en prueba de corrección geométrica; debe acompañarse de outputs de tests.
