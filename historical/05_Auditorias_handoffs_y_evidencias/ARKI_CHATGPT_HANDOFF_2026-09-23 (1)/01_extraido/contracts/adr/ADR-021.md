# ADR-021 — Migraciones de esquema

**Estado:** Aprobado para ejecución de E6  
**Fecha:** 2026-09-23

## Decisión

Session, Project, Version, Snapshot y AuditEntry llevan `schemaVersion`. IndexedDB ejecuta migraciones versionadas al abrir.

## Reglas

- Cada migración tiene función y prueba dedicada.
- No se permite downgrade destructivo.
- Si el código es más antiguo que los datos, se rechaza la apertura y se solicita actualización.
- Antes de migrar se conserva una exportación gobernada cuando sea posible.
