# ADR-002 — Modelo intermedio de escena

**Estado:** Aprobado para E5 Revisado  
**Fecha:** 2026-09-23

## Decisión

El visor consume un `SceneModel` derivado determinísticamente de `ConstructionModel`. El renderer no debe convertir directamente el dominio constructivo en cada componente visual.

El contrato vigente es `shared/arkiSceneModel.ts` con schema `ARKI-SCENE-MODEL-1.0`.

## Reglas

- `ConstructionModel` sigue siendo la fuente constructiva canónica.
- `SceneModel` es una proyección de presentación 3D, no una segunda ontología constructiva.
- Cada nodo conserva identidad, tipo, nivel, dimensiones, posición, color, opacidad y relaciones.
- Las extensiones son aditivas y deben conservar compatibilidad con el E5-PREVIEW.
- No se modifica `ConstructionModel`, `Muro`, `StructuralElement` ni los DTOs canónicos para implementar el visor.

## Consecuencia

La misma entidad puede alimentar planta 2D, visor 3D, Info Box y futuros adaptadores IFC mediante contratos de identidad comunes.
