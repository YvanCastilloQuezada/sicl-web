# CFMI Adversarial Test Matrix v1.0

| Scenario | Required result |
|---|---|
| Three photographs | Insufficient understanding |
| One reference facility | No typological generalization |
| Missing process/safety | Research required / not ready |
| Missing specialist calculation | Specialist required |
| Equipment without maintenance envelope | Explicit unknown |
| International standard | Not automatically local law |
| Famous or large facility | No automatic exemplar |
| Documented vs suspected failure | Cause state preserved |
| Process/equipment change | Spatial/logistics consequences |
| Security-sensitive source | Restricted detail not ingested |
| Critical unknown at readiness gate | No unconditional READY |
| New class | Knowledge acquisition before generation |
| Oracle output | Not silently canonical |
