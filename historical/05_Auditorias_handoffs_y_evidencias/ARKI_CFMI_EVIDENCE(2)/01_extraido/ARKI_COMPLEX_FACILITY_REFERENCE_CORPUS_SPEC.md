# ComplexFacilityReferenceCorpus v1.0

The reference corpus is a governed LKS view, not a second canonical database. Each record preserves facility identity, class, mission, location, jurisdiction, operators/designers/engineers, scales, disciplines, processes, systems, sources, standards, lifecycle, evidence, provenance, access classification and unknowns.

Reference facility ≠ template; one project ≠ typological knowledge.
