# ARKI Complex Facilities & Megaproject Intelligence — CFMI-001

**Maximum status:** FOUNDATION IMPLEMENTED / BOUNDED PILOT / PENDING INDEPENDENT VERIFICATION

CFMI is a governed LKS view for complex facilities, critical infrastructure and megaprojects. It is process-first: mission → process → activities → equipment → performance/safety → utilities/logistics → maintenance → space/systems/facility. It does not declare professional competence or create specialist agents.
