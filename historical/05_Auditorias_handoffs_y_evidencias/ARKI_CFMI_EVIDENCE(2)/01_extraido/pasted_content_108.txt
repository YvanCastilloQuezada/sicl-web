ADENDA 97A-04 — ARKI COMPLEX FACILITIES & MEGAPROJECT INTELLIGENCE
Exceptional Facilities + Critical Infrastructure + Process Architecture + Multiscale Megaproject Knowledge

Orden matriz: ORDEN 97A — ARKI Living Knowledge Integration v1.1
Programa: ARKI-LKS-001 — ARKI Living Knowledge System
Antecedentes: 97A-01 KCF + 97A-02 ACI + 97A-03 HAI
Código provisional: ARKI-CFMI-001
Tipo: Mandatory Knowledge Architecture + Facility Intelligence + Research + Evidence Addendum
Prioridad: HIGH / STRATEGIC
Autoridad: Product Owner / Human Authority

Esta Adenda NO reemplaza ni reinicia 97A ni sus adendas anteriores.

Amplía el conocimiento gobernado de ARKI hacia instalaciones, infraestructuras y megaproyectos cuya complejidad excede normalmente el ámbito de los concursos arquitectónicos convencionales.

CFMI-01. MISIÓN

Crear dentro del Living Knowledge System una capacidad gobernada para que ARKI pueda:

COMPRENDER, ESTRUCTURAR, COMPARAR Y PROGRESIVAMENTE RAZONAR SOBRE INSTALACIONES COMPLEJAS, INFRAESTRUCTURAS CRÍTICAS Y MEGAPROYECTOS, INTEGRANDO ARQUITECTURA, TERRITORIO, PROCESOS, INGENIERÍA, EQUIPAMIENTO, LOGÍSTICA, SEGURIDAD, CONSTRUCCIÓN, OPERACIÓN Y CICLO DE VIDA.

El objetivo futuro es permitir que ARKI pueda participar responsablemente en proyectos de complejidad internacional creciente.

Esta Adenda NO declara competencia profesional actual en dichas instalaciones.

CFMI-02. PRINCIPIO FUNDAMENTAL

Formalizar:

A COMPLEX FACILITY IS NOT SIMPLY A LARGE BUILDING.

MEGAPROJECT ≠ BIG BUILDING.

FACILITY IMAGE ≠ FACILITY UNDERSTANDING.

EQUIPMENT GEOMETRY ≠ SYSTEM KNOWLEDGE.

KNOWING A FACILITY EXISTS ≠ KNOWING HOW TO DESIGN IT.

CFMI-64. ADVERSARIAL TESTS

Como mínimo:

tres fotografías de una instalación → insufficient for understanding;
one reference facility → no typological generalization;
missing process → RESEARCH_REQUIRED;
missing safety knowledge → not READY;
missing specialist calculation → SPECIALIST_REQUIRED;
equipment known but maintenance envelope unknown → explicit UNKNOWN;
reference facility uses feature X → not automatically requirement;
international standard → not automatically local law;
facility is famous → no automatic exemplar status;
large project → no automatic quality;
documented failure → preserve actual cause;
suspected failure cause → hypothesis only;
process change → propagate spatial consequences;
equipment change → maintenance/logistics consequences;
CITY/REGION requirement → no automatic COMPONENT rule;
operational requirement → influences design when evidence supports;
security-sensitive source → do not ingest/reconstruct restricted detail;
knowledge present but solver absent → computation NOT_DEMONSTRATED;
FacilityReadinessGate with critical UNKNOWN → cannot return unconditional READY;
ARKI cannot self-certify professional specialist competence;
new Facility Class → knowledge acquisition before generation;
Reference Corpus item → cannot directly become canonical principle;
failure corpus → no causal overclaim;
specialist/oracle output → does not silently become canonical fact.
