# E2 — Wireflows, controles y pruebas de los 16 módulos

## Estado

**E2 preparado para revisión — sin código de producto.**

E2 traduce el flujo de vida de Archi a controles, zonas de pantalla, wireflows y casos de aceptación. No implementa tecnologías nuevas ni abre E3.

## Entregables

1. Contrato global de controles y estados.
2. Matriz de controles de los 16 módulos.
3. Wireflows del ciclo de vida.
4. Catálogo de pruebas funcionales.

## Criterio de cierre

E2 se aprueba cuando el Product Owner confirma que cada módulo tiene contexto, canvas, inspector, acciones, estados y prueba mínima. Un caso de prueba descrito no equivale a una prueba ejecutada.

## Límites

El visor 3D real, la persistencia IndexedDB, IFC4, OpenSees, MEP productivo, Avatar, Luka y conectores externos permanecen fuera de la implementación de E2.
