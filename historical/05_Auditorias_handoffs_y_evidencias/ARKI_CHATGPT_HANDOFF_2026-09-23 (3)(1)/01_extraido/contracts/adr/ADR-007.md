# ADR-007 — Parser IFC4 con web-ifc

**Estado:** Aprobado para ejecución de E6  
**Fecha:** 2026-09-23

## Decisión

E6 autoriza `web-ifc` como parser IFC4/WASM detrás de un adaptador gobernado. La integración se valida primero con una prueba mínima de Vite/React 19.

## Reglas

- El parser declara formatos soportados y no soportados.
- Toda pérdida se registra en `lossReport`.
- La carga WASM requiere configuración explícita y no puede ocultar errores.
- Si el parser no es compatible con el entorno, Bloque B queda PARTIAL y se abre E6-bis.

## Límites

Este ADR no autoriza RVT/RFA, DXF, firma profesional ni round-trip sin fixtures IFC reales.
