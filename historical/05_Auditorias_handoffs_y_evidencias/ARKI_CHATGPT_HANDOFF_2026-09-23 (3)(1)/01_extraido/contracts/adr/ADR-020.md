# ADR-020 — Auditoría con cadena de hashes

**Estado:** Aprobado para ejecución de E6  
**Fecha:** 2026-09-23

## Decisión

Cada modificación persistente produce un `AuditEntry` con `chainHash = sha256(previous.chainHash + afterHash)`. El primer registro usa un valor genesis gobernado.

## Reglas

`verifyAuditChain` debe detectar el primer registro roto y marcar inválida la cadena desde ese punto. No se permite editar retrospectivamente una entrada.

## Límite

La cadena de hashes detecta alteración; no constituye firma digital ni identidad legal.
