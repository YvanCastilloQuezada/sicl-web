# ADR-005 — Snapshots aprobados

**Estado:** Aprobado para ejecución de E6  
**Fecha:** 2026-09-23

## Decisión

Un snapshot sólo puede alcanzar `passed` cuando la versión tiene `modelHash`, identidad estable, AuditEntry de creación, responsable de aprobación, ausencia de errores pendientes y padre válido cuando corresponda.

## Estados

`pending → passed | failed`

Las versiones usan:

`draft → review → approved → frozen → archived`

## Límites

`approvedBy` y el hash son trazabilidad de aplicación; no son firma digital profesional.
