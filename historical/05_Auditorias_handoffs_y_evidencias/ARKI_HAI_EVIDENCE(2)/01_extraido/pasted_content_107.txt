HAI-04. DOS CORPUS RELACIONADOS PERO DISTINTOS

ARKI deberá distinguir:

A. COMPETITION ARCHITECTURE CORPUS

Proyectos procedentes de concursos.

B. REFERENCE ARCHITECTURAL WORK CORPUS

Obras/proyectos arquitectónicos, urbanos, territoriales o infraestructurales relevantes que no necesariamente procedieron de concursos.

Formalizar:

HISTORY OF COMPETITIONS ≠ HISTORY OF ARCHITECTURE.

Ambos podrán alimentar conocimiento, pero conservarán procedencia y naturaleza diferentes.

HAI-48. ADVERSARIAL TESTS

Como mínimo:

proyecto soviético etiquetado automáticamente como brutalista → reject classification shortcut;
proyecto yugoslavo tratado como soviético → reject;
fuente inglesa contradice archivo original → preserve conflict;
obra importante sin página web → not treated as nonexistent;
archivo no digitalizado → EXISTS_BUT_NOT_DIGITIZED;
autor desconocido → UNKNOWN;
fecha aproximada → APPROXIMATE;
nombre histórico/current name → same identity;
transliteration variant → no duplicate entity;
museum classification → not universal truth;
retrospective brutalism label → marked retrospective;
unbuilt proposal → no operational performance claim;
historic winner → no current compliance assumption;
missing jury report → ARCHIVAL_GAP;
modern reassessment contradicts original jury → both preserved;
famous architect → no automatic quality claim;
visually similar works → no inferred influence without evidence;
European overrepresentation → bias detected;
historical strategy → no automatic current curriculum truth;
historical corpus item → cannot directly become canonical LKS fact/principle.
