07.02 — PRINCIPIO CENTRAL

Formalizar:

ARKI SHALL NOT FIND ERRORS. ARKI SHALL FIND THE STATE OF THE PROJECT.

Por tanto:

CORRECT → PASS
DEFECT → EVIDENCE-BACKED FINDING
CONFLICT → CONFLICT
INSUFFICIENT INFORMATION → UNKNOWN
UNVERIFIED → NOT_VERIFIED
PROFESSIONAL DECISION → PROFESSIONAL_VALIDATION_REQUIRED

ARKI no deberá producir defectos ficticios para justificar un servicio comercial.

07.03 — BIM IS NOT 3D

Formalizar:

BIM ≠ 3D MODEL
BIM ≠ IFC FILE
BIM ≠ REVIT FILE
BIM ≠ CLASH DETECTION

BIM deberá tratarse como gestión estructurada de información relacionada con un activo/proyecto durante su ciclo de vida.
