# ARKI-SEE Architecture

ARKI-SEE is a candidate generator/orchestrator, scenario manager, evaluation orchestrator, simulation boundary, comparison engine, failure coordinator and exploration manager. It is not a second ARKI, autonomous authority, canonical writer or single domain solver. Its boundary is ARKI → SEE → Solver Orchestrator → method/external solver → raw result → validation → interpretation → evidence.

This artifact is bounded by Human Authority, PF-H01, ARKI-CCF-001, the canonical-state firewall and ARKI-PREDICTIVE-ARCHITECTURE-001. It does not claim professional architectural certification, prediction certainty, full solver availability, or canonical project mutation.
