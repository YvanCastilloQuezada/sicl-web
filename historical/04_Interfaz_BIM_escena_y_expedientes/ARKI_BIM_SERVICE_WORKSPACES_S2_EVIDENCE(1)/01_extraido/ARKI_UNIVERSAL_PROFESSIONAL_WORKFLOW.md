# Universal Professional Workflow

**Estado:** PROFESSIONAL SERVICE WORKSPACE FOUNDATION / INTERNAL TESTING / PENDING INDEPENDENT VERIFICATION

## Shared core

This workspace is one view of one ARKI job. It reuses the canonical portal job state, `BIMFinding`, `BIMRequirementMatrix`, `BIMRepair`, input manifests and evidence provenance. It does not create a second issue system or project state.

## Human boundary

ARKI may screen, derive, compare and recommend. Material decisions, professional validation, contractual acceptance and redesign remain human-authorized. `UNKNOWN` remains visible.

## Workflow

Customer input → input freeze → preflight → processing → ARKI self-QA → red team → provisional result → professional review → observations → correction/information request/escalation → revalidation → final review → delivery.

A result is not a professional delivery. Delivery labels distinguish ARKI generated, QA checked, professionally reviewed and professionally validated.
