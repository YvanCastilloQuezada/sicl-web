# 02 — Definición canónica de MiLukita

MiLukita es el ecosistema de experiencias, identidad, territorio, medios, control y gobernanza que rodea a LUKA. No es sinónimo de MJP CORE ni de una sola pantalla.

**LUKA** es la identidad/protagonista de las experiencias. **LUKALLPA** representa el mundo/territorio cuando el modelo conceptual lo usa. **MiLukita** es la plataforma/ecosistema que conecta usuarios, dispositivos, contenido, territorio y controles. **MJP CORE** es un núcleo protegido con autoridad propia sobre reglas, RNG, RTP, wallet, ledger, settlement y manifest.

La relación correcta es:

```text
MiLukita / LUKA experiences → proponen, muestran, capturan o controlan
MJP CORE → conserva autoridad sobre dominios protegidos
Human Authority → decide publicación territorial y gobernanza
```

Fuentes: `client/src/App.tsx`, `shared/territorialTrust.ts`, `shared/mjpCoreIsolation.test.ts`, `shared/agentRegistry.ts` y `drizzle/schema.ts`.
