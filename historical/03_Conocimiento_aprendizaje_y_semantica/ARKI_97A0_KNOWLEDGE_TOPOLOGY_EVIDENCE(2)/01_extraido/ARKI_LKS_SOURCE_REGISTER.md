# ARKI LKS — Initial Source Register

**Status:** staged research evidence; not canonical knowledge.

## LKC-001-IFC

| Source | Role | Observed fact |
|---|---|---|
| [ISO 16739-1:2024](https://www.iso.org/standard/84123.html) | Normative primary source | IFC 4.3 / ISO publication metadata and scope |
| [buildingSMART IFC](https://www.buildingsmart.org/standards/bsi-standards/industry-foundation-classes/) | Official industry source | IFC/openBIM scope, versions and related standards |
| [IFC technical specifications](https://technical.buildingsmart.org/standards/ifc/ifc-schema-specifications/) | Official technical source | Schema, encodings and version semantics |
| [IFC 4.3 release](https://standards.buildingsmart.org/IFC/RELEASE/IFC4_3/) | Release source | Static release baseline |
| [IDS](https://www.buildingsmart.org/standards/bsi-standards/information-delivery-specification-ids/) | Official related standard | Machine-readable information requirements |
| [BCF](https://www.buildingsmart.org/standards/bsi-standards/bim-collaboration-format/) | Official related standard | Issue communication, not IFC ontology |

**Cautions:** IFC version does not define an ARKI mapping; MVD/IDS, identifiers, units, properties, relationships, round-trip and loss rules remain unproven for ARKI.

## LKC-003-URBAN-DIGITAL-TWIN

| Source | Role | Observed fact |
|---|---|---|
| [OGC UDT position paper](https://docs.ogc.org/dp/24-025.html) | Official position paper | UDT concepts and interoperability cautions |
| [OGC UDT DWG](https://www.ogc.org/groups/urban-digital-twins-domain-working-group/) | Official working group | Standards and use-case coordination |
| [OGC UDT interoperability pilot](https://docs.ogc.org/per/24-067r1.html) | Pilot report | Prototype interoperability, not universal product conformance |
| [OGC CityGML](https://www.ogc.org/standards/citygml/) | Standard | 3D city model semantics and geometry |
| [OGC SensorThings](https://www.ogc.org/standards/sensorthings/) | Standard | IoT observations/API component |
| [EU Local Digital Twin Toolbox](https://interoperable-europe.ec.europa.eu/collection/ldttoolbox) | Official EU collection | Modular toolbox; simulation focus is not real-time operation |
| [UK NDTP principles](https://www.gov.uk/government/publications/what-a-digital-twin-is-and-how-you-can-contribute/national-digital-twin-programme-ndtp-principles) | Official government principles | Security, ethics, sustainability and interoperability principles |
| [ISO/IEC UDT/CIM item](https://www.iso.org/standard/87250.html) | Official standard status | Under-development status must not be treated as final standard |

**Cautions:** 3D model, digital representation, observed data and simulation are distinct. UDT synchronization, governance, privacy, identity, temporal state and feedback remain project-specific.
