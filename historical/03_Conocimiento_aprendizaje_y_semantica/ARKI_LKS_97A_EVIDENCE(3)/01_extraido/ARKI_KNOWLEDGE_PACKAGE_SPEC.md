# ARKI Knowledge Package Specification v1.1

The ARKI Knowledge Package is a versioned, derived view. It is not a new database or owner.

It can reconstruct references to knowledge, sources, claims, evidence, standards, curriculum, competencies, capabilities, gaps and temporal history. It preserves unknowns and original evidence references. It exposes owners and derived views and explicitly marks `canonicalPromotionAllowed: false` unless a separate Human Authority policy allows promotion.

The package must not copy evidence into a second truth, must not collapse standards into ARKI ontology, and must not turn a view into a semantic owner.
