# ARKI 97A — LKS Migration Decisions

| Existing artifact | Decision | Rationale |
|---|---|---|
| AKI-001 | PRESERVE_HISTORICAL + INTEGRATE references | It is the verified diagnostic baseline and must not be rewritten |
| Historical curriculum | DERIVE_VIEW | It is not a current living curriculum owner |
| Competency Matrix | DERIVE_VIEW | It separates exposure, practice, test and verification; no second registry |
| Knowledge Gaps | INTEGRATE | Gaps feed the existing LKS Gap Register |
| Knowledge Book deltas | PRESERVE_HISTORICAL | BKH/AKI history must remain intact |
| LKS v1 | REUSE_AS_IS then EXTEND | It is the common existing owner |
| Academy/Tutor/Examiner/Oracle | MIGRATE_LATER | Documentary roles; runtime not found |
| PCB-001 | UNKNOWN | Dedicated executable artifact not found |
| IFC | INTEGRATE | LKC-001 plus existing IFC capability evidence |
| Smart Cities / UDT | INTEGRATE | Existing LKC-002 and LKC-003 remain views in one LKS |
| Standards references | INTEGRATE | No StandardsRegistry #2 permitted |
| ISO baseline | ADAPT within LKS | Metadata-level, non-exhaustive and access-limited |
| Knowledge Package | DERIVE_VIEW | It must not become a second owner |

`SUPERSEDE_WITH_TRACEABILITY` is not used to erase history. Any future supersession must retain predecessor, reason, evidence and Human Authority decision.
