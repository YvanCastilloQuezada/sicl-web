# ARKI LKS v1.1 — Integrated Architecture

## Target

`ONE ARKI · ONE GOVERNED KNOWLEDGE SYSTEM · MULTIPLE SEMANTIC VIEWS · HUMAN AUTHORITY`

The existing `shared/arkiLivingKnowledge.ts` remains the common owner for governed external knowledge records, evidence, epistemic transitions, source versioning, change detection and derived views. AKI-001 remains a historical diagnostic baseline and is referenced, not duplicated.

## Layers

```text
SOURCE → CLAIM → CURATION → KNOWLEDGE → PREREQUISITE
→ CURRICULUM VIEW → COMPETENCY EVIDENCE → CAPABILITY/GAP VIEWS
→ HUMAN AUTHORITY
```

Standards are an LKS family. IFC, ISO, OGC, Smart Cities and UDT retain their own semantics and authority; cross-standard mappings are typed relations, never ontology collapse.

## Separation

`KNOWLEDGE`, `CURRICULUM`, `COMPETENCE`, `CAPABILITY`, `IMPLEMENTATION`, `EVIDENCE` and `AUTHORITY` are separate semantic dimensions. `IMPLEMENTED` never implies competent; verified competence never implies professional authority.

## Current implementation delta

The LKS runtime now provides composition for curriculum views, standards records, curriculum deltas, competency revalidation, conflict records and a derived Knowledge Package. No second database, registry or canonical owner was created.

## Boundaries

Academy/Tutor/Examiner/Oracle remain documentary/proposed roles. PCB-001 remains unspecified and not implemented. Standards ingestion is initial and non-exhaustive. No autonomous learning, mass regulatory ingestion, kernel mutation, scheduler activation or canonical promotion is enabled.
