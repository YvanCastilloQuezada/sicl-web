# ARKI Competency Revalidation Specification v1.1

A competency is evaluated against the knowledge version and evidence that originally supported it. Historical evidence is immutable.

States: `STILL_VALID`, `REVIEW_REQUIRED`, `PARTIALLY_STALE`, `STALE`, `UNKNOWN`.

A material requirement change produces `REVIEW_REQUIRED`; a non-material version change produces `PARTIALLY_STALE` unless independently cleared. No state is promoted to professional authority. Revalidation preserves what was demonstrated, against which version, when, by which evidence and what changed afterwards.

Teaching, implementation and a successful single project fixture cannot directly produce verified competence.
