# Readiness State Model

Readiness is distinct from implementation status. DIGEST-001 uses READY_FOR_ASSIMILATION, PARTIAL_REUSE, REUSE_AVAILABLE, DEPENDENCY_BLOCKED, TOOL_DEFICIT, EVIDENCE_DEFICIT, KNOWLEDGE_DEFICIT, CONTRADICTION_DETECTED, PROFESSIONAL_VALIDATION_REQUIRED, HUMAN_DECISION_REQUIRED, and NOT_READY.
