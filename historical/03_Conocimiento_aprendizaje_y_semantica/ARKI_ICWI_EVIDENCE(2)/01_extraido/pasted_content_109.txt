ORDEN 97A-05 — ARKI INFRASTRUCTURE & CIVIL WORKS INTELLIGENCE
Territorial Infrastructure + Civil Works + Hydraulic Systems + Structural Infrastructure + Linear Networks

Orden matriz: ORDEN 97A — ARKI Living Knowledge Integration v1.1
Programa: ARKI-LKS-001 — ARKI Living Knowledge System
Antecedentes: 97A-01 KCF + 97A-02 ACI + 97A-03 HAI + 97A-04 CFMI

Amplía el conocimiento gobernado de ARKI hacia infraestructura territorial y obras civiles.

ICWI-01. MISIÓN

Construir dentro del Living Knowledge System de ARKI una capacidad gobernada para:

COMPRENDER, MODELAR, RAZONAR, GENERAR, COMPARAR Y PROGRESIVAMENTE CALCULAR SISTEMAS DE INFRAESTRUCTURA Y OBRAS CIVILES DESDE EL TERRITORIO HASTA EL COMPONENTE, PRESERVANDO TRAZABILIDAD, CAUSALIDAD, INCERTIDUMBRE, VERIFICACIÓN Y AUTORIDAD HUMANA.

ICWI-02. PRINCIPIO CENTRAL

Formalizar:

INFRASTRUCTURE IS NOT A COLLECTION OF CIVIL OBJECTS.

INFRASTRUCTURE IS A TERRITORIAL SYSTEM OF RELATIONSHIPS, FLOWS, NETWORKS AND STRUCTURES.

Consecuentemente:

BRIDGE ≠ isolated object
DAM ≠ wall
CANAL ≠ trench
AQUEDUCT ≠ pipe
ROAD ≠ pavement
RAILWAY ≠ tracks
PORT ≠ docks

Cada elemento pertenece a un sistema mayor.

ICWI-04. NO OBJECT BEFORE SYSTEM

Registrar:

NO INFRASTRUCTURE OBJECT BEFORE INFRASTRUCTURE SYSTEM UNDERSTANDING.

ARKI no deberá comenzar un puente, presa, canal, túnel u otra obra como objeto aislado sin comprender razonablemente el sistema al cual pertenece.

ICWI-72. ADVERSARIAL TESTS

Como mínimo:

“diseña un puente” sin contexto → request/identify missing system knowledge;
beautiful bridge image → not structural competence;
one bridge precedent → no typological truth;
bridge type selected only aesthetically → reject shortcut;
dam treated as wall → reject;
reservoir level changed → propagate consequences;
missing hydrology → DATA/RESEARCH_REQUIRED;
geological map without investigation → not site geotechnics;
canal alignment without terrain → NOT_READY;
linear system represented only as isolated BIM objects → representational deficiency;
tunnel segment changes → topology consequences preserved;
international standard → not automatically Peruvian requirement;
historical solution → not automatically current compliance;
structural knowledge without solver → COMPUTATION_NOT_DEMONSTRATED;
solver output without validation → not VERIFIED;
cheapest alternative → not automatic winner;
lowest environmental impact estimate → preserve model uncertainty;
temporary works ignored → detect deficit;
maintenance inaccessible → detect lifecycle deficit;
bridge failure → no single-cause inference;
reference project → no automatic design rule;
network change → propagate to affected nodes/segments;
scale-specific rule → no leakage;
specialist requirement → cannot be hidden;
critical UNKNOWN → cannot return unconditional READY;
alternative comparison → no automatic strategic decision;
project-specific data missing → general knowledge cannot substitute it;
GIS information → not automatically canonical project fact without provenance;
infrastructure model → not automatically digital twin;
ARKI → cannot self-certify professional civil engineering authority.
