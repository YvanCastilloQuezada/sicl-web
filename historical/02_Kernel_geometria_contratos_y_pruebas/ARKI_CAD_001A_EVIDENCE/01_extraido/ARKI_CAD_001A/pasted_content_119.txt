2. Candidatos obligatorios

Manus deberá evaluar como mínimo:

A. Open Design Alliance — Drawings SDK

ODA dispone de SDK para DWG/DXF y declara capacidades de acceso a propiedades, geometría y jerarquía, conversión, visualización y extracción. Su paquete Core cubre además IFC, DGN, STEP y otros formatos, lo que podría ser estratégicamente interesante para ARKI más allá de ABB-001.

Debe analizarse particularmente porque ARKI pretende convertirse en un servicio corporativo/web. La licencia comercial básica de ODA no permite Web/SaaS; actualmente ODA publica Sustaining como nivel que sí permite Web/SaaS y uso comercial ilimitado, con precio publicado de US$7,500 el primer año y US$4,500 de renovación, sujeto naturalmente a las condiciones contractuales vigentes cuando se contrate.

No comprar ninguna licencia en esta orden.

B. Autodesk RealDWG

RealDWG deberá analizarse como referencia de máxima fidelidad Autodesk.

Autodesk lo describe como su SDK para leer y escribir DWG/DXF “from the source” y declara compatibilidad DWG completa dentro de su ámbito soportado.

Hay una desventaja arquitectónica importante para nuestro servidor: RealDWG 2027 actualmente especifica Windows 11 como sistema operativo, mientras nuestra arquitectura corporativa ARKI pretende utilizar principalmente servidores Linux.

Eso no lo descarta. Podría conducir a:

ARKI Linux Cluster
        │
        ▼
CAD WINDOWS WORKER
        │
    RealDWG
        │
        ▼
      ACIR

Pero debe justificarse el costo operativo de introducir ese worker Windows.

C. GNU LibreDWG

Debe evaluarse como alternativa abierta.

GNU LibreDWG es una biblioteca C libre para lectura/escritura DWG, GPLv3+, y su documentación declara cobertura de lectura amplia hasta DWG R2018, aunque también documenta áreas todavía incompletas o menos probadas.

Por tanto:

OPEN SOURCE
≠
AUTOMATICALLY PRODUCTION SUITABLE

Debe evaluarse técnicamente y jurídicamente la compatibilidad de GPLv3+ con la futura arquitectura comercial de ARKI.

D. ODA File Converter — solo como baseline/diagnóstico

ODA actualmente ofrece su File Converter para Windows, Linux y macOS y permite convertir DWG↔DXF.

Pero ODA aclara que Viewer/File Converter son proyectos de ejemplo y que para no miembros su uso es no comercial.

Por tanto:

puede evaluarse como herramienta diagnóstica/benchmark no comercial, pero no debe introducirse silenciosamente como infraestructura comercial de ARKI.

9. Regla crítica

No introducir todavía:

LINE → WALL
BLOCK → DOOR
POLYLINE → ROOM
CIRCLE → PIPE

Eso pertenece a la futura capa de interpretación semántica.

ACIR MUST REPRESENT WHAT THE CAD SAYS, NOT WHAT ARKI THINKS IT MEANS.

10. Server architecture

Linux
   │
   ▼

Autodesk confirma actualmente que AutoCAD no es compatible nativamente con Linux y no recomienda Wine como entorno soportado.
