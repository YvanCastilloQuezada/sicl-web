# Solver Architecture

```text
ARKI
  ├─ Problem Definition
  ├─ Solver Selection
  ├─ Input Compiler + Unit/Applicability Validation
  ├─ Solver Adapter
  ├─ Isolated Execution Worker
  ├─ Output Parser
  ├─ Validation / Cross-Solver Checks
  ├─ Evidence Envelope
  ├─ Interpretation
  └─ Dependency Propagation (proposal only)
```

Adapters are instruments, not canonical owners. They cannot commit canonical state, certify professional work or bypass Human Authority. Representation, calculation, validation and professional interpretation remain separate boundaries.
